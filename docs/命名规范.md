# 命名规范

本文档适用于 HIDController 项目的所有 C++ 和 Python 代码，包括公开 API、内部实现和测试代码。**所有代码必须严格遵守本规范**，本规范优先级高于任何外部参考文档。

---

## C++ 命名规范

| 类别 | 风格 | 示例 |
|---|---|---|
| 类 / 结构体 / 枚举类型 | `PascalCase` | `ImageProcessor`, `NetworkSession` |
| 函数（成员函数、自由函数） | `snake_case` | `process_image()`, `get_session_status()` |
| 局部变量 / 函数参数 | `snake_case` | `image_data`, `session_id` |
| 非静态成员变量 | `snake_case_` 后缀 | `session_id_`, `cache_` |
| 静态成员变量（编译期常量） | `kPascalCase` | `kMaxConnections` |
| 静态成员变量（运行时可变） | `s_snake_case_` | `s_instance_` |
| 常量 / `constexpr` 变量 | `kPascalCase` | `kMaxRetries`, `kPi` |
| 宏 | `UPPER_SNAKE_CASE` | `HID_CONTROLLER_VERSION` |
| 命名空间 | `snake_case` | `hid_controller::core` |
| 模板参数 | `PascalCase` | `typename RequestType` |
| 枚举值（枚举类） | `kPascalCase` | `Status::kOk`, `Color::kRed` |
| 异常类型 | `PascalCase` + `Error`/`Exception` | `NetworkError`, `ParseException` |
| 回调类型别名 | `PascalCase` + `Callback`/`Handler` | `OnDataCallback` |
| Concept（C++20） | `PascalCase` | `Readable` |
| 测试用例名 | `snake_case` | `is_valid`, `handles_timeout` |
| 源文件 / 头文件 | `snake_case.cpp` / `.h` | `image_processor.cpp`, `network_session.h` |
| 测试文件 | `snake_case_test.cpp` | `image_processor_test.cpp` |

### 必须遵守的补充规则

| 规则 | 正确示例 | 错误示例 |
|---|---|---|
| 布尔值使用 `is_`/`has_`/`should_` 前缀 | `is_ready()`, `has_data()` | `ready()`, `data_available()` |
| 禁止 Hungarian notation | `session_id` | `pSessionId`, `iCount` |
| Getter（返回 const 引用） | `const std::string& session_id() const` | `get_session_id()` |
| Getter（返回值拷贝） | `std::string name() const` | `get_name()` |
| Setter | `void set_session_id(const std::string& id)` | `session_id(const std::string& id)` |
| 移动构造函数 / 移动赋值 | 必须标记 `noexcept` | 省略 `noexcept` |
| 不可拷贝类 | 显式 `= delete` 拷贝构造和赋值 | 仅注释说明 |
| 转移所有权的方法 | `take_` 前缀 | `release_buffer()` |

## Python 命名规范

严格遵循 PEP 8，不得例外。

| 类别 | 风格 | 示例 |
|---|---|---|
| 模块 / 包 | `snake_case` | `image_processor.py`, `core/` |
| 类 | `PascalCase` | `ImageProcessor`, `NetworkSession` |
| 异常类 | `PascalCase` + `Error`/`Exception` | `ValidationError` |
| 函数 / 方法 | `snake_case` | `process_image()`, `get_session_status()` |
| 变量（局部/全局） | `snake_case` | `image_data`, `session_id` |
| 模块级常量 | `UPPER_SNAKE_CASE` | `MAX_RETRIES`, `DEFAULT_TIMEOUT` |
| `@property` 属性 | `snake_case` | `session_id`, `timeout` |
| 内部成员（私有约定） | `_snake_case` 前导单下划线 | `_cache`, `_update_metrics()` |
| 名称修饰（防子类冲突） | `__snake_case` 双前导下划线 | `__private_attr` |
| 魔法方法 | `__xxx__` | `__init__`, `__len__` |
| 类型别名 | `PascalCase` | `UserId` |
| 测试文件 / 测试函数 | `test_` 前缀 | `test_image_processor.py`, `test_process()` |
| 回调 / 事件处理器 | `on_` 前缀或 `_handler` 后缀 | `on_click()`, `error_handler` |

### Python 必须遵守的补充规则

| 规则 | 正确示例 | 错误示例 |
|---|---|---|
| 禁止 `camelCase` 用于函数/变量 | `process_image()` | `processImage()` |
| 缩写词在类名中保持一致 | 项目统一使用 `HttpSession` 或 `HTTPSession`，选定后不得混用 | 混用 `HttpSession` 和 `HTTPSession` |
| 单字符变量仅限极短作用域 | `for i in range(10):` | 在 50 行函数中使用 `i` 作为有意义变量 |
| 类和函数之间空两行 | 类定义后空两行再定义函数 | 不空行或仅空一行 |
| 避免关键字冲突 | `class_` | `class` |

## 跨语言一致性（公开 API）

C++ 和 Python 的**公开 API 名称必须完全一致**，降低用户学习成本。

| 用途 | C++ | Python |
|---|---|---|
| 类 / 类型 | `PascalCase` | `PascalCase` |
| 公开函数 | `snake_case` | `snake_case` |
| 变量 | `snake_case` | `snake_case` |
| 文件名 | `snake_case.cpp` / `.h` | `snake_case.py` |

### 公开 API 对照示例

| 功能 | C++ | Python |
|---|---|---|
| 创建会话 | `create_session()` | `create_session()` |
| 处理数据 | `process_data()` | `process_data()` |
| 获取版本 | `get_version()` | `get_version()` |
| 只读属性 | `const std::string& session_id() const` | `@property def session_id(self)` |
| 读写属性 | `session_id()` + `set_session_id()` | `@property` + `@session_id.setter` |

### 目录结构

| 语言 | 目录 |
|---|---|
| C++ 公开头文件 | `include/hid_controller/` |
| C++ 源文件 | `src/` |
| C++ 测试文件 | `tests/`，命名 `*_test.cpp` |
| Python 包 | `src/hid_controller/` |
| Python 测试文件 | `tests/`，命名 `test_*.py` |

- 存量代码在修改时逐步迁移至本规范
